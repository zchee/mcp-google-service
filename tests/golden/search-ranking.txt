# Expected head of the ranking `Catalog::search` produces over the committed
# snapshot (`data/catalog-snapshot.json`). Checked by `tests/search_ranking.rs`.
#
# Format: a `query:` line, then the namespaced tool names expected at the head
# of the result list, in rank order. `(no hits)` pins an empty result. A block
# pins exactly as many positions as it lists; what follows them is unpinned.
# Blank lines and `#` lines are ignored.
#
# These are the first tools a model is shown for each query, so a change here
# is a behaviour change, not a refresh. Edit it on purpose with the reason in
# the commit message; never regenerate it from the code under test. The
# `cloud run` block is the real-model E2E finding of 2026-08-20: the ranking
# put BigQuery-related tools above Cloud Run's own.
